Third-party shaders in this package
===================================

The plugin's own code is Apache-2.0. The mpv GLSL shaders under shaders/ are
third-party files, redistributed under their own licences: MIT (Anime4K,
CfL), the Unlicense (the two Anime4K AutoDownscalePre files), AMD's MIT
licence (FSR), BSD-2-Clause (adaptive-sharpen) and, since 0.3.0, LGPL-3.0
(RAVU, FSRCNNX, SSimDownscaler). Every file keeps its copyright and licence
notice in its header. The directories of the permissive ones hold their
licence text as LICENSE; every directory with LGPL-3.0 shaders holds the
full LGPL-3.0 text as COPYING.LESSER and the GPL-3.0 text, which the LGPL
supplements, as COPYING. All of them are unchanged, byte for byte as
upstream published them, except CfL_Prediction_Lite.glsl (see cfl/ below).
The LGPL-3.0 files are separate files the plugin hands to the player's mpv
as they are; they are never combined with the plugin's code.

The records at the end ("File:" ... "License:") name, for every shader but
the modified CfL file, its upstream repository, commit, path (or, for a
release asset, its download URL) and the sha256 of its bytes, which the
shipped file has too.

anime4k/
  Anime4K by bloc97 and contributors
  https://github.com/bloc97/Anime4K
  Version: release v4.0.1 (tag v4.0.1, commit
    4029bf701ecaa15f163cdc49cffe5501c1acf410); the files are those of the
    release asset Anime4K_v4.0.zip, the same bytes as glsl/ at that commit
  Licence: MIT, Copyright (c) 2019-2021 bloc97 (anime4k/LICENSE), except
    Anime4K_AutoDownscalePre_x2 and _x4: the Unlicense (public domain; the
    text is in each file's header)
  Files: Anime4K_Clamp_Highlights, Anime4K_AutoDownscalePre_x2/_x4,
    Anime4K_Restore_CNN_{UL,VL,M,S}, Anime4K_Restore_CNN_Soft_{UL,VL,M,S},
    Anime4K_Upscale_CNN_x2_{UL,VL,M,S},
    Anime4K_Upscale_Denoise_CNN_x2_{UL,VL,M} (the UL ones since 0.3.0, for
    Ultra)
  The presets follow the upstream mpv templates, taken from the master
  branch (commit 7684e9586f8dcc738af08a1cdceb024cc184f426; the v4.0.1 tag
  does not contain them):
  md/Template/GLSL_Mac_Linux_High-end/input.conf (HQ) and
  md/Template/GLSL_Mac_Linux_Low-end/input.conf (Fast). Upstream has no
  template for the UL networks; Ultra is the High-end template with UL in
  place of VL, as md/GLSL_Instructions_Advanced.md allows ("Shader
  variants (S/M/L/VL/UL) can be chosen at will").

cfl/
  Chroma from Luma (CfL) Prediction, Lite variant, by Artoriuz (João
  Chrisóstomo)
  https://github.com/Artoriuz/glsl-chroma-from-luma-prediction
  Version: commit 066dff964b83aa34e893de25d590874bf8c8e94f (2026-08-15,
    includes "Gate regression by luma extrapolation distance", the fix for
    blue artifacts on flat-luma chroma detail), file CfL_Prediction_Lite.glsl,
    sha256 of the upstream file 159c1dad4daab10eddaae822a5d0fb0b94a38e85a2825fb7df9d7feb509ad4f7
  Licence: MIT, Copyright (c) 2023 João Chrisóstomo (cfl/LICENSE, the
    repository's LICENSE)
  Files: CfL_Prediction_Lite.glsl
  Modified for this plugin, syntax only, so that it compiles as GLSL 4.10
    (macOS OpenGL 4.1 with mpv's vo_gpu): the C-style initializer lists became
    array constructors (initializer lists need GLSL 4.20) and the array of
    arrays chroma_quads[4][2] became chroma_quads_u[4] and chroma_quads_v[4]
    (arrays of arrays need GLSL 4.30). The computation is unchanged. A note
    after the licence header in the file says so.
    sha256 of the shipped, modified file 817c43f5c8dfbe81e01d4ac4fc03f9c7f8fd266276459bfda9fa119b17c9fe34

ravu/
  RAVU-lite-AR (radius 3), by bjin (Bin Jin), since 0.3.0
  https://github.com/bjin/mpv-prescalers
  Licence: LGPL-3.0-or-later, as each file's header says (the repository's
    README: "Shaders in this repo are licensed under terms of LGPLv3"). The
    header names no copyright holder. Texts: COPYING.LESSER and COPYING
    next to each file.
  Files (both unchanged; the plugin picks one per platform):
    ravu/rgba16hf/gather/ravu-lite-ar-r3.hook, for Windows (mpv's vo_gpu
      with Direct3D 11 has no rgba16f texture format): branch rgba16hf,
      path gather/ravu-lite-ar-r3.hook
    ravu/master/gather/ravu-lite-ar-r3.hook, for macOS and the others
      (OpenGL; rgba16f texture): branch master, path
      gather/ravu-lite-ar-r3.hook
  The gather/ variants use textureGather (GLSL 4.00), upstream's first
  recommendation for luma prescalers; no compute shaders. The generator of
  these files is on the repository's source branch.
