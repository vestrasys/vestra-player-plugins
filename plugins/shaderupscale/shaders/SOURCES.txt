Third-party shaders in this package
===================================

The plugin's own code is Apache-2.0. The mpv GLSL shaders under shaders/ are
third-party files, redistributed under their own permissive licences, with
line endings normalised to LF: MIT (Anime4K, CfL), the Unlicense (the two
Anime4K AutoDownscalePre files), AMD's MIT licence (FSR) and BSD-2-Clause
(adaptive-sharpen). Every file keeps its copyright and licence notice in its
header, and each directory holds the licence text as LICENSE. All of them are
unchanged except CfL_Prediction_Lite.glsl (see cfl/ below).

anime4k/
  Anime4K by bloc97 and contributors
  https://github.com/bloc97/Anime4K
  Version: release v4.0.1, asset Anime4K_v4.0.zip
  Licence: MIT, Copyright (c) 2019-2021 bloc97 (anime4k/LICENSE), except
    Anime4K_AutoDownscalePre_x2 and _x4: the Unlicense (public domain; the
    text is in each file's header)
  Files: Anime4K_Clamp_Highlights, Anime4K_AutoDownscalePre_x2/_x4,
    Anime4K_Restore_CNN_{VL,M,S}, Anime4K_Restore_CNN_Soft_{VL,M,S},
    Anime4K_Upscale_CNN_x2_{VL,M,S}, Anime4K_Upscale_Denoise_CNN_x2_{VL,M}
  The presets follow the upstream mpv templates, taken from the master
  branch (the v4.0.1 tag does not contain them):
  md/Template/GLSL_Mac_Linux_High-end/input.conf (HQ) and
  md/Template/GLSL_Mac_Linux_Low-end/input.conf (Fast).

cfl/
  Chroma from Luma (CfL) Prediction, Lite variant, by Artoriuz (João
  Chrisóstomo)
  https://github.com/Artoriuz/glsl-chroma-from-luma-prediction
  Version: commit 066dff964b83aa34e893de25d590874bf8c8e94f (2026-08-15,
    includes "Gate regression by luma extrapolation distance", the fix for
    blue artifacts on flat-luma chroma detail), file CfL_Prediction_Lite.glsl,
    sha256 of the upstream file 159c1dad4daab10eddaae822a5d0fb0b94a38e85a2825fb7df9d7feb509ad4f7
    (with its CRLF line endings)
  Licence: MIT, Copyright (c) 2023 João Chrisóstomo (cfl/LICENSE, the
    repository's LICENSE)
  Files: CfL_Prediction_Lite.glsl
  Modified for this plugin, syntax only, so that it compiles as GLSL 4.10
    (macOS OpenGL 4.1 with mpv's vo_gpu): the C-style initializer lists became
    array constructors (initializer lists need GLSL 4.20) and the array of
    arrays chroma_quads[4][2] became chroma_quads_u[4] and chroma_quads_v[4]
    (arrays of arrays need GLSL 4.30). The computation is unchanged. A note
    after the licence header in the file says so.
