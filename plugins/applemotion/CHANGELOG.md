# Changelog

## 0.1.0

- First version: motion smoothing with Apple's frame interpolation through the player (`plugin.video.motion("apple")`): VideoToolbox's frame processor on Apple silicon Macs. Video ▸ Apple Motion Smoothing… opens a window with the mode (Off, Double Frame Rate, Match Display), what it does and needs, and a status line with the player's reason when a mode waits or cannot work here. Three commands choose a mode in one step from the command palette and Ask Vestra (*Apple Motion Smoothing: Off*, *Double Frame Rate (Smoother Video)*, *Match Display (Smoothest Motion)*), radio items checked on the saved mode and greyed out with the player's reason where a mode cannot work for the whole run. Off by default; the chosen mode is saved and asked for again at each start. Needs a Mac with Apple silicon and macOS 15.4 or newer, and the first Vestra Player release with the Apple engine (`minPlayerVersion`). How large a video the Mac keeps up with is the player's call: a size it fell behind on waits with the player's reason for the rest of the run; HDR waits too. While the window is open and the converter runs, steady dropped frames show a hint with what helps, as in AMD and NVIDIA Motion Smoothing. A store icon (`assets/icon.png`, 256 × 256): the same ghost trail as the AMD and NVIDIA plugins', with rounded squares in a blue-to-violet gradient. Translations: Simplified Chinese, Japanese, Korean, German, French and Spanish.
